# 1.4.1

- Preserve existing audio when recordings, imports, or merges happen within the same second.
- Keep complete Unicode text, including emoji and combining characters, when splitting transcripts into summary chunks.
- Reject zero or negative chunk sizes without hanging or crashing. Stored invalid settings show a local error and preserve existing content.
- Keep Native transcription failures local. Switching to a server now requires selecting that provider explicitly.
- Require a selected summary model and valid HTTP(S) endpoint before sending transcript or title requests. Keyless local services remain supported.
- Remove direct transcript, generated-title, and malformed-response payload dumps from application diagnostics.
- Correct setup documentation for macOS 26, default FluidAudio transcription, summary configuration, and ZIP installation. Add synthetic native regressions and targeted UI coverage.

Requires macOS 26 or later. The ZIP contains a universal app for Apple silicon and Intel Macs. Signing remains ad-hoc; the app is not notarized.
